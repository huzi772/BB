# Audio Files Directory

This directory contains sound effects and background music for the Cinematic Birthday Surprise application.

Expected audio files:
- `background-music.mp3` - Ambient atmospheric background music track
- `countdown-hit.mp3` - Impact sound effect for countdown digits
- `transition-whoosh.mp3` - Cinematic scene transition whoosh
- `magical-shimmer.mp3` - Shimmer / sparkle sound effect
- `candle-blow.mp3` - Sound of blowing air / wind for candle
- `candle-extinguish.mp3` - Soft sizzle / flame extinguishing sound
- `birthday-reveal.mp3` - Triumphant birthday reveal musical chord / jingle
- `gift-open.mp3` - Unwrapping / box opening sound effect
- `envelope-open.mp3` - Paper slide / envelope unsealing sound
- `fireworks.mp3` - Fireworks launch and burst sounds
